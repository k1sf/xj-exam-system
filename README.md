# 快速部署脚本

# 这是一个简化版的部署指南
# 适合零基础用户

## 步骤 1: 下载项目文件

请从当前系统中下载以下文件：

1. api/[[...path]].ts
2. lib/db.ts  
3. public/index.html
4. vercel.json
5. package.json
6. tsconfig.json
7. .env.example

## 步骤 2: 上传到 GitHub

1. 创建 GitHub 仓库
2. 上传所有文件

## 步骤 3: 在 Vercel 部署

1. 导入 GitHub 仓库
2. 设置环境变量
3. 点击部署

详细步骤请查看 DEPLOY.md 文件。
